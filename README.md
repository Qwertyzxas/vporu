# Впору

Сайт корпусной мебели на заказ: Тимур Войтенко, Тольятти и 50 км вокруг.

Next.js 16 (статический экспорт), React 19, TypeScript, CSS Modules, Three.js и React Three Fiber, Lenis.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # готовый сайт в папке out
npm start          # посмотреть собранную версию
```

Для хостинга нужна только папка `out`: её загружают на любой хостинг статических сайтов.

## Что где менять

Все тексты и контакты лежат в одном файле: [src/content/site.ts](src/content/site.ts).

- `contacts`: телефон, Telegram, WhatsApp, VK, часы работы. `maxUrl` сейчас ведёт на web.max.ru; когда появится ссылка на твой профиль в MAX, вставь её сюда.
- `metrikaId`: номер счётчика Яндекс Метрики. Пока строка пустая, счётчик не подключается. Цели уже размечены: `order_submit`, `order_whatsapp`, `order_telegram`, `order_max`, `order_vk`, `phone`, `hero_order`, `header_order` и другие.
- `letter.portrait`: твоё фото для блока «Работаю сам». Положи файл в `public/images/` и впиши путь, например `"/images/timur.jpg"`.

Картинки описаны в [src/content/media.ts](src/content/media.ts) вместе с авторами и лицензиями. Подписи с авторами выводятся в подвале сайта.

## Как устроена страница

- `components/workshop`: 3D-шкаф. Он собран кодом из панелей, при прокрутке разлетается на детали с выносками и собирается обратно. Состояние сцены считается чистой функцией `sceneAt()` от прокрутки.
- `Furniture`, `Process`, `Materials`: виды мебели, шаги работы и материалы сеткой. Блоки мягко проявляются при прокрутке.
- `Faq`: вопросы-аккордеон.
- `Order`: заявка с живым чертежом. Тип мебели выбирается чипсами. Кнопки WhatsApp, Telegram, MAX и VK открывают чат с уже собранным текстом заявки, сервер не нужен.
- `Letter`: «Работаю сам», цитата и три факта (`letter.facts` в site.ts).
- `Footer`: короткая нижняя строка, контакты живут в заявке и вопросах.
- В шапке надпись `promise` из site.ts.
- Фон один на всю страницу: тёплый орех с лёгкой текстурой дерева.
